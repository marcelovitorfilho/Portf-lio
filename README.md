### EntregaProva
**Projeto Makers · AI Lab (Ciclo B2B 2026)** · `GCP` `Firebase` · **Atuação: QA**

Plataforma para transportadoras regionais comprovarem entregas mais rápido e faturarem o frete sem atrasos, trocando canhotos físicos por um fluxo digital.

- Captura do comprovante pelo celular (foto, recebedor, data e hora)
- Conciliação com os dados do XML de NF-e/CT-e
- Painel de pendências e aging por embarcador
- Geração do pacote de comprovação para faturamento
- **Meu papel:** QA, garantindo a qualidade e a confiabilidade das entregas do projeto
